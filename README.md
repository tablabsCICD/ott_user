## Local Dart Defines

This project uses `String.fromEnvironment` for values such as the Razorpay key.

For local VS Code runs:

1. Create `.vscode/dart_defines.json` using `.vscode/dart_defines.example.json` as the template.
2. Set `RAZORPAY_KEY_ID` to your real Razorpay key.
3. Run the `Flutter Chrome (local defines)` or `Flutter Windows (local defines)` launch configuration.
